Each field reading will be recorded with the phone model, app version, carrier, network type, timestamp, GPS accuracy, and the condition it was taken in. Readings are planned outdoors while standing still, since that is one of the two conditions the FCC models, and any reading that has to be taken indoors will be flagged. The FCC data will be tracked by the map's "as of" date and last updated date, along with the technology and speed threshold used in each comparison. The OpenCellID download date will be noted too, as that database changes over time. Without these details, a gap between predicted and real coverage could come from the phone or the setting instead of the network itself. All of this metadata will be kept in a plain text file called metadata_plan.txt in the same folder as the data.
